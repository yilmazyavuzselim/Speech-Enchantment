Dataset & Implementation Specs

Sampling Rate: 16,000 Hz, 16-bit PCM Mono WAV
Model: Causal Demucs DNS48 (waveform U-Net + LSTM bottleneck, hidden=48)
Loss Function: Multi-Resolution STFT (3 resolutions) + L1 loss
Demo Files: 20 WAV files, 3,741,710 total bytes, verified SHA-256 byte-for-byte identical to source evaluation outputs.
